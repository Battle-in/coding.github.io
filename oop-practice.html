Цели занятия

После выполнения практики вы должны уметь:

  • объявлять класс и создавать объекты (экземпляры);
  • описывать атрибуты объекта и инициализировать их в __init__;
  • писать методы экземпляра, которые используют self;
  • различать метод экземпляра, класса (@classmethod) и статический (@staticmethod) — на базовом уровне;
  • вызывать методы и интерпретировать результат работы программы.

Краткая теория

Класс — шаблон данных и поведения. Объект — конкретный экземпляр класса.

Минимальный класс

class Point:
    pass  # пустой класс

p = Point()
p.x = 10  # атрибут можно добавить «снаружи», но так обычно не делают

Конструктор __init__

Метод __init__ вызывается при создании объекта. В нём задают начальное состояние через self.

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

a = Point(0, 0)
b = Point(3, 4)

Метод экземпляра

Первый параметр — всегда self (ссылка на текущий объект). Вызов: obj.method(...) — Python сам передаёт self.

Разбор примера: «Банковский счёт»

Изучите код. Запустите его у себя и измените суммы пополнения — проследите, как меняется баланс.

class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Сумма пополнения должна быть положительной")
        self.balance += amount

    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError("Сумма снятия должна быть положительной")
        if amount > self.balance:
            raise ValueError("Недостаточно средств")
        self.balance -= amount

    def info(self):
        return f"Владелец: {self.owner}, баланс: {self.balance}"


if __name__ == "__main__":
    acc = BankAccount("Аня", 1000)
    acc.deposit(500)
    acc.withdraw(200)
    print(acc.info())

Вопросы для самопроверки:

  1. Что хранится в acc.owner и acc.balance после всех операций?
  2. Зачем проверки в deposit и withdraw?
  3. Чем info отличается от deposit по возвращаемому значению?

Виды методов (для задания 4)

Тип Декоратор Первый аргумент Когда использовать
Экземпляра — self Работа с данными конкретного объекта
Класса @classmethod cls Альтернативные конструкторы, фабрики объектов
Статический @staticmethod нет self/cls Вспомогательная логика, логически связанная с классом 
class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius

    @classmethod
    def from_fahrenheit(cls, f):
        c = (f - 32) * 5 / 9
        return cls(c)

    @staticmethod
    def is_boiling(celsius):
        return celsius >= 100

t = Temperature.from_fahrenheit(212)
print(Temperature.is_boiling(t.celsius))  # True

Задания

Рекомендуется один файл oop_practice.py или отдельный файл на каждое задание. В конце каждого задания добавьте блок демонстрации (как в примере с if __name__ == "__main__").

базовый Задание 1

Класс «Студент»

Создайте класс Student с полями: full_name, group, grades (список оценок, по умолчанию пустой).

  • add_grade(grade) — добавляет целую оценку от 2 до 5; иначе ValueError.
  • average() — средний балл; если оценок нет, вернуть None.
  • is_excellent() — True, если средний балл ≥ 4.5 и все оценки не ниже 4.

Демо: создайте двух студентов, добавьте оценки, выведите средний балл и статус «отличник».

базовый Задание 2

Класс «Прямоугольник»

Класс Rectangle: ширина и высота (width, height), задаются в __init__, только положительные числа.

  • area() — площадь;
  • perimeter() — периметр;
  • scale(factor) — умножает стороны на factor (> 0), изменяет объект «на месте», ничего не возвращает.

Демо: создайте прямоугольник 3×4, выведите площадь и периметр, затем scale(2) и снова площадь.

средний Задание 3

Класс «Корзина покупок»

Класс ShoppingCart хранит список позиций. Каждая позиция — словарь {"name": str, "price": float, "qty": int}.

  • add_item(name, price, qty=1) — если товар с таким именем уже есть, увеличить qty, иначе добавить новую позицию. Цена и количество должны быть > 0.
  • remove_item(name, qty=1) — уменьшить количество; при нуле удалить позицию. Если товара нет — KeyError с понятным сообщением.
  • total_price() — сумма price * qty по всем позициям.
  • __str__ — человекочитаемое описание корзины (список строк).

Демо: добавьте 3 разных товара, частично удалите один, выведите print(cart) и итоговую сумму.

средний Задание 4

Класс «Событие в календаре»

Класс CalendarEvent: title, duration_minutes (целое > 0).

  • Обычный метод extend(minutes) — увеличить длительность.
  • @classmethod from_hours(cls, title, hours) — создать событие, переведя часы в минуты.
  • @staticmethod is_long(duration_minutes) — True, если длительность > 120 минут.

Демо: создайте событие через from_hours, вызовите extend, проверьте is_long до и после продления.

продвинутый Задание 5*

Композиция: «Библиотека» (по желанию)

Класс Book: title, author, is_available (bool). Класс Library хранит список книг.

  • Library.add_book(book), find_by_title(title) — первая книга с таким названием или None.
  • borrow(title) — если книга есть и доступна, is_available = False; иначе поднять осмысленное исключение (LookupError или ValueError).
  • return_book(title) — вернуть книгу на полку.

Используйте объекты Book внутри Library, а не отдельные словари — это и есть композиция.

Критерии проверки

  • Классы названы в стиле CapWords, методы — snake_case.
  • Атрибуты инициализируются в __init__, а не «висят» только снаружи.
  • Методы используют self для доступа к полям объекта.
  • Некорректный ввод обрабатывается (исключения или явные проверки по условию задания).
  • Есть рабочий демо-блок; программа запускается без ошибок.
  • Код читаемый: осмысленные имена, без дублирования одной и той же логики в пяти местах.

Подсказки и типичные ошибки

Ошибка: забыли self

def area(width, height):  # так метод не увидит поля объекта
    ...

Правильно: def area(self): и использовать self.width, self.height.

Ошибка: изменяемый аргумент по умолчанию

def __init__(self, grades=[]):  # опасно: один список на все объекты!

Используйте grades=None и внутри self.grades = grades if grades is not None else [].
